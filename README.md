## Problem Area

Cyber Security - Personal Digital Safety

## Problem

Everyday digital users may receive suspicious messages, emails, links,
QR codes and phone calls. Users may not know whether an interaction is
safe or what action they should take.

## Project Focus

The project explores the problem of helping users recognize, understand
and respond to common cyber threats such as:

- Data breaches
- Phishing links
- Malicious QR codes
- Scam calls
- Social engineering

## Phase 1 Status

This repository contains the project documentation and evidence
collection structure for Phase 1 Customer and Problem Validation.

User validation evidence will be added only after conducting genuine
stakeholder conversations.

## Evidence

The evidence folder contains anonymized documentation of genuine
stakeholder conversations and findings.

No passwords, OTPs, financial information, private messages or other
sensitive personal information should be included.
