# Project Evidence

This folder contains evidence collected for Phase 1 customer and
problem validation.

## Evidence collection

The team will conduct meaningful conversations with:

- Primary digital users
- Other digital users
- A cybersecurity-aware person or relevant stakeholder

Each conversation will focus on:

1. A real cyber-related occurrence
2. The user's current workflow
3. The difficulty experienced
4. The consequence or impact
5. How the user currently responds or reports the issue

## Privacy

All evidence will be anonymized.

The repository will not contain:

- Passwords
- OTPs
- Bank details
- Phone numbers
- Personal email addresses
- Private messages
- Other confidential information

Only information permitted for public assessment will be uploaded.
